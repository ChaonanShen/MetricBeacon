题目 

基于自然语言交互的、可沉淀的、可观测性指标分析工作台

描述：
 团队用 Prometheus 打点、Grafana 监控，存在几个问题：
  1. 监控面板的呈现视角难以事先想全，排查分析时经常发现有面板视角不够，手动改图很低效。
  2. 监控面板的指标众多、图表众多，排查分析时经常在找到对应的监控图这个事情上耗时间。
  3. 监控面板手动配置警报，在排查分析问题之后，固化分析过程的负担太重，经验也难以沉淀。

解决方案：
  1. 基于自然语言交互的智能实时图表生成平台，可以动态生成、编辑图表。
  2. 基于会话做持久化，会话可以分享、fork。
  3. 基于会话做类 skill 沉淀，形成更为精简、易于复用的 playbook。
  4. 进一步探索自动化异常发现、根因分析的可能性。

基础目标：
  1. 基于自然语言交互，自动生成可交互图表。
  2. 多图表同屏展示、图表可动态编辑（手动、自然语言）。
  3.  会话持久化，可持续分析。
  4. 可联动知识库等提升问题理解和图表生成准确率。

进阶目标：
  1. 知识沉淀：自动沉淀可复现的、参数化的 playbook。
  2. 进一步智能化：下一步提示、异常指标发现、根因分析。
  3. 交互便利性：实时语音交互。
